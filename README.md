SireChat

SireChat is a web-based messaging application that enables users to communicate, share images and videos, and access their chat history.

Status: In Development — Ongoing Improvements

Live Demo · GitHub Repository

Features

* User registration and authentication
* Messaging between users
* Image and video sharing using Cloudinary
* User profiles and chat-related data stored in Cloud Firestore
* Password-reset functionality
* Responsive chat interface

Features and reliability are still being reviewed and improved.

Technology Stack

Technology	Purpose

Getting Started

Prerequisites

* Node.js
* npm
* Git

Installation

git clone https://github.com/Prince-Akpadie/sireChat.git
cd sireChat
npm install

Configure the Firebase and Cloudinary environment variables required by the application in a local .env file.

Start the development server:

npm run dev

Available Scripts

Command	Description
npm run dev	Start the development server
npm run build	Build for production
npm run preview	Preview the production build
npm run lint	Run ESLint checks
