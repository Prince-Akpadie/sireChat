# SireChat

**SireChat** is a web-based chat application designed to make online communication simple and accessible through a clean, user-friendly interface.

[Live Demo](https://sirechat.vercel.app) · [GitHub Repository](https://github.com/Prince-Akpadie/sireChat)

## Overview

SireChat is a messaging application project developed by Prince Akpadie. It focuses on providing users with an accessible interface for communicating online.

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/)
- npm
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Prince-Akpadie/sireChat.git
   ```

2. Navigate to the project directory:

   ```bash
   cd sireChat
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

### Production Build

Build the application for production:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```
